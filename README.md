# Batch File Renamer 📁✨

A lightweight, powerful Python command-line utility designed to batch rename files efficiently. Built using Python's standard libraries (`argparse` and `pathlib`), it supports adding prefixes, suffixes, text replacements, and a secure dry-run mode to preview changes before applying them.

## Features
* **Prefix & Suffix Addition:** Easily tag groups of files.
* **Find & Replace:** Swap out specific substrings in filenames seamlessly.
* **Dry-Run Mode:** Preview exact alterations without altering a single file on your system.
* **Zero Dependencies:** Uses strictly built-in Python libraries (`argparse`, `pathlib`).

## Requirements
* Python 3.6 or higher.

## Usage Guide

Run the script from your terminal using the following syntax:

```bash
python renamer.py <directory_path> [options]
